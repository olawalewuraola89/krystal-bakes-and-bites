# Krystal Bakes and Bites

React + Vite site based on the reference design.

## Run it
```bash
npm install
npm run dev
```
Open the URL Vite prints (usually http://localhost:5173).

## Where things live
- `src/data/content.js`  all text, prices, nav, image paths, contact details
- `src/index.css`        colour/type tokens and shared button/link styles
- `src/components/*`     one component + one CSS file per section
- `public/images/`       your photos (see the README.txt in there for filenames)
